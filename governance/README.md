## הצהרת כשרות — הטענה המרכזית של האתר

האתר טוען שכל 50 המתכונים כשרים. זו טענה עובדתית שצריכה גיבוי, ולכן מתועדת כאן.

**מה נאכף, ואיך אומת:**

| כלל | אכיפה | ראיה |
|---|---|---|
| אין חזיר | סריקת ביטויים על **רשימת המצרכים בפועל** בשתי השפות | 0 ממצאים |
| אין פירות ים | אותה סריקה (שרימפס/סרטן/צדפות/קלמרי/תמנון…) | 0 ממצאים |
| דגים בעלי סנפיר וקשקשת בלבד | סריקה לדגים אסורים + בדיקה ידנית של 3 מתכוני הדגים | דניס, לברק, בקלה, מושט — כולם כשרים |
| **אין ערבוב בשר וחלב** | הצלבה אוטומטית: מתכון עם מצרך בשרי **ו**מצרך חלבי נכשל בבנייה | 0 ממצאים |
| `kosherType` תואם למצרכים | מוצלב מול המצרכים, לא מול הכותרת — מתכון שמסומן פרווה ומכיל חלב נכשל בבנייה | 0 ממצאים |

האימות רץ ב-`build.mjs` **לפני** כתיבת ה-JSON: אם כלל נשבר, שום קובץ לא נכתב.

**התפלגות:** בשרי 14 · חלבי 2 · פרווה 34.

**החלפות מפורשות שנעשו לשם כשרות:** בטאג׳ין הכבש, המרוזיה, הפסטייה והקוסקוס המסורתיים מופיע *סמן* (חמאה מותססת) לצד בשר. בכל המתכונים האלה הוחלף בשמן זית, וההוראות אומרות זאת במפורש.

**מה ההצהרה *לא* מכסה — מתועד גם בפוטר ובתנאי השימוש:** לאתר **אין תעודת כשרות ואין השגחה רבנית**. כשרות המוצרים עצמם תלויה בהשגחה שעל האריזה שהמשתמש קונה (יין, חומץ יין, ג׳לטין, גבינה, בשר). האתר מתאר מתכונים, לא מעניק הכשר.
